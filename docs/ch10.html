第 10 章　排错、安全与继续学习

约 3 分钟 · 1,638 字 · 8 个小节

本章你会学会

  • 用一张表定位常见问题；
  • 知道去哪里看诊断信息；
  • 建立自己的安全清单；
  • 控制成本；
  • 规划继续练习的路线。

10.1 常见问题对照表

现象 先检查什么 常见原因
打不开/连不上模型 设置 → 模型 Key 错、Base URL 错、没余额
401 Invalid API key API Key 复制不完整、过期、服务不匹配
Agent 不回复/一直转 模型、网络、会话 服务超时、上下文过大
Agent 说没有工具 当前模式、插件状态 选了极简模式、插件没启用
插件装了但没工具 Plugin Manager、重载 没启用、需要重启、依赖缺失
Skill 不加载 Skill 目录、版本 路径不对、描述不匹配、版本冲突
改文件被拒绝 权限/工作区 不在工作区、沙箱限制
找不到文件 工作区、相对路径 当前目录不对、文件不存在
越聊越慢/越贵 上下文 历史太长、读了太多文件
Agent 重复/忘事 上下文 窗口满、压缩、旧信息干扰
工具名冲突 插件列表 两个插件注册了同名工具
插件报版本错误 版本 DSH/CLI/插件版本不匹配
运行命令卡住 命令本身 交互式命令、无超时、网络阻塞

10.2 怎么读诊断信息

先看界面

  • 红色错误；
  • 工具卡片的失败原因；
  • Plugin Manager 的 warnings；
  • 模型设置的状态。

再看上下文

  • 当前工作区对不对；
  • 当前模式对不对；
  • 当前插件是否启用；
  • 当前 Session 是否太长。

最后看日志

Desktop/CLI 通常会有日志或诊断入口。CLI 用户可以：

dsh --profile web --dump-config

查看实际组合的配置。不要在不理解的情况下直接改 profile 文件。

一个通用排查顺序

1. 最小复现
2. 换新 Session
3. 换标准模式
4. 停用最近装的插件
5. 检查模型/网络
6. 检查工作区/权限
7. 看日志/诊断
8. 再考虑重装/回滚

10.3 安全清单

每次开始重要任务前，问自己：

[ ] 工作区是不是只包含需要的文件？
[ ] 重要文件有没有备份/git 提交？
[ ] 是否只需要只读？能不能先只读？
[ ] 是否要执行删除/覆盖/推送/上传？
[ ] 是否要把密钥/密码/隐私数据给它看？
[ ] 插件来源是否可信？
[ ] 是否真的需要 full access？
[ ] 出问题怎么回滚？

三条底线

  1. 密钥不进对话；
  2. 破坏性操作先备份、先确认；
  3. 不信任的插件不给高权限。

10.4 成本与用量

Agent 的成本主要来自 token：

  • 上下文越长，越贵；
  • 读大文件、长网页，会显著增加；
  • 子代理/工作流会额外调用模型；
  • 频繁重试也会增加。

省钱习惯

  • 只读需要的文件；
  • 长文档分段；
  • 任务完成就总结成文件，换新 Session；
  • 不用子代理时不要开；
  • 选合适的模型，不要所有任务都用最贵的。

10.5 继续学习路线

第 1 周：日常使用

  • 用标准模式完成 3 个真实任务；
  • 练习“目标 + 输入 + 约束 + 验收”；
  • 学会看工具卡片和审批。

第 2 周：工作区与上下文

  • 给项目写 AGENTS.md；
  • 用 PROJECT.md / PROGRESS.md 管理长任务；
  • 练习新 Session 恢复。

第 3 周：工具与技能

  • 用 todo 管理多步任务；
  • 试一个子代理；
  • 读一个 Skill 的 SKILL.md；
  • 用 present 交付文件。

第 4 周：扩展

  • 读第 8 章，理解 Plugin/Bundle/Profile；
  • 在创造模式里做一个小工具；
  • 学会安装、验证、卸载；
  • 写一份自己的插件说明。

10.6 一页纸速查

Agent = Model + Harness

日常任务 → 标准模式
扩展 DSH → 创造模式
批量工具 → PTC
小任务   → 极简模式

工作区 = 文件夹 + 权限边界
Session = 一次对话
Context = 工作内存，会满
Skill   = 知识/流程
Tool    = 动作
Plugin  = 运行时能力
Bundle  = 安装包
Profile = 安装环境
Preset  = 单 Agent 的能力组合

好任务 = 目标 + 输入 + 约束 + 验收
先只读，再写入
先计划，再执行
破坏性操作先备份
密钥不进对话

小结

  • 排错从“最小复现 + 新 Session + 标准模式 + 停用新插件”开始。
  • 安全三条底线：密钥、备份、权限。
  • 成本主要来自上下文和模型调用。
  • 学习路线：日常 → 工作区 → 工具/技能 → 插件。
  • 先会用，再扩展；不要一上来做很大的插件。
