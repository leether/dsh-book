About this book

An unofficial, practical introduction to DSH for people who are about to let an Agent read files, run tasks, and change real things. It does not try to document every API. It builds the right habits first: use a small workspace, start read-only, plan before executing, and ask for evidence before accepting. This English edition was edited for natural English usage; corrections are welcome.
